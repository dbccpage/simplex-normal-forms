# Status Labels

Status: Definitional.

Use these labels for definitions, claims, and contracts.

| Label | Meaning |
|---|---|
| Definitional | term, field, category, or notation definition |
| Operational semantics | executable or verifier-oriented behavior definition |
| Conditional theorem | theorem under stated finite hypotheses |
| Proof obligation | claim that must be proved or discharged before promotion |
| Mechanization target | intended theorem/test/verifier implementation |
| Experimental conjecture | quarantined idea without full finite verifier discipline |
| Domain extension | application of the substrate to a non-core domain |

Promotion rule: a contract cannot move from experimental/domain extension into the core taxonomy without finite carrier, evidence obligations, terminal routes, non-claims, and verifier tests.

Non-claims: does not replace Codd / relational theory; does not claim all data problems are normal forms; does not claim certification equals authorization; does not claim metadata creates authority; does not require category theory for implementation; does not prove all experimental regimes.
