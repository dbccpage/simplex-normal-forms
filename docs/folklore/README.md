# Folklore and Comedy Namespace

Status: Comedy diagnostic.

This namespace is for non-normative diagnostic names only. It is intentionally outside the core taxonomy.

Allowed use:

- memorable labels for recurring failure patterns
- historical notes about terminology that should not enter contracts
- jokes or folklore that help identify a smell during review

Forbidden use:

- adding comedy names to core normal forms
- adding folklore labels to machine-readable contracts
- using humor as evidence, proof, or authority

Non-claims: does not replace Codd / relational theory; does not claim all data problems are normal forms; does not claim certification equals authorization; does not claim metadata creates authority; does not require category theory for implementation; does not prove all experimental regimes.
